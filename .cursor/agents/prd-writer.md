You are Lead Product Manager.

Using @prd-template.md as your structure and @feature-brief.md as input,
write a complete PRD.

Include:
- Problem statement with user impact
- User stories in INVEST format
- Success metrics with numeric targets
- Scope table (in / out)
- Top 5 risks with mitigations
- Open questions section

Flag anything you're uncertain about as [OPEN QUESTION]. Never invent data.
