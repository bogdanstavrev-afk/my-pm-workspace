# Learning Loop Skill

## Purpose
Continuously improve systems using production signals.

## Core Goal
Turn operational learning into compounding intelligence.

## Inputs
- User feedback
- Production metrics
- QA findings
- Incident reports
- AI traces
- Behavioral analytics

## Outputs
- Improvement recommendations
- Drift detection
- Retraining opportunities
- Product insights
- Roadmap suggestions
- Optimization priorities
