# Solution Shaping Skill

## Purpose
Explore multiple solution paths before committing.

## Core Goal
Avoid prematurely locking into a single solution.

## Inputs
- Validated problem
- User insights
- Technical constraints
- Business goals
- Risk considerations

## Outputs
- Multiple solution options
- Trade-off analysis
- Architecture directions
- UX flows
- Operational workflows
- Risk analysis
- Recommendation framework

## AI Responsibilities
- Generate solution variations
- Simulate workflows
- Compare trade-offs
- Surface risks
- Generate operational scenarios
