# Evaluation & Testing Skill

## Purpose
Validate quality, safety, reliability, and real-world performance.

## Core Goal
Prevent unsafe or low-quality AI-native releases.

## Inputs
- Product flows
- Models
- Policies
- Test datasets
- Evaluation criteria
- Production telemetry

## Outputs
- Evaluation reports
- Risk reports
- Safety findings
- Model performance analysis
- Reliability scores
- QA outcomes
